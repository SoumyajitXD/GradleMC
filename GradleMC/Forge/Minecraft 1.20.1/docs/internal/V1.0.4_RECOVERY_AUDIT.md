# GradleMC Forge 1.20.1 v1.0.4 recovery audit

Date: 2026-07-23.  Scope is the active Forge workspace, with the read-only
Fabric 1.20.1 client source as the UX donor and the shipped 1.1.0 JAR treated
as forensic-only evidence.

## Runtime trace

`GradleMC` registers common config, commands, networking, and server services.
`ClientModEventHandler` registers key mappings and the overlay only on `Dist.CLIENT`.
`ClientEventHandler` records post-GUI rendered frames, opens the GUI, and pauses
sampling outside active gameplay. `GradleMCGuiOpener` now opens
`LegacyGradleMCScreen`; that screen invokes existing commands/network services
and `OverlayConfigActions`, rather than duplicating diagnostics.

## Forensic JAR

The supplied `gradlemc-1.1.0-forge-1.20.1.jar` was not used as implementation
authority. Its manifest and `mods.toml` both identify `GradleMC 1.1.0`, Forge
1.20.1, loader range `[47,)`, and `gradlemc`. It contains the adaptive, smart,
report, network, overlay and workspace GUI class families, but contains the
newer `GradleMCScreen` and no `LegacyGradleMCScreen`; that is direct evidence
that its GUI is not the recovered active screen. The current source retains
the useful bounded backend families while restoring `LegacyGradleMCScreen` as
the only GUI opener target.

## Phase 2 incremental correction

Normal adaptive samples previously decayed local player signals after the
score was calculated and did not synchronize a new client snapshot. This made
the client-facing value look frozen at the configured calm base (`8/100`)
until an unrelated damage/death event or explicit status request. Samples now
decay, recalculate, and send one authoritative compact update per 40 ticks;
this is bounded and is not render-driven traffic. The `8` remains a documented
calm adaptive-risk baseline, not a Technical Stability Score or confidence
claim.

## Phase 3 recovery continuation

Settings now use a client-local `OverlaySettingsDraft`: edits are staged; Apply validates and saves once; Cancel, Escape and Back discard. Failed saves restore prior in-memory config values while retaining the draft.
