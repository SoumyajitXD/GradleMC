# GradleMC Forge 1.20.1 v1.0.4 — final GUI restoration audit

**NOT READY.** The active Forge `LegacyGradleMCScreen` was a 169-line
approximation, not a port of the Fabric donor's 1,160-line `GradleMCScreen`.
This document records the exact authority and the remaining port requirement;
it must not be used to claim visual parity.

## Style contract

`LegacyGuiStyle` contains direct donor values: content width `380..840`, header `58`, footer `34`, sidebar `128`, tab `22`, button `20`, margin `14`, gap `8`, line height `11`, scroll step `18`, and donor background/panel/border/text/status colours. `LegacyGuiLayout` is the donor `layoutFor` calculation, adapted only into a loader-neutral record.

`LegacyGuiLayoutSelfTest` verifies the contract and three required logical viewports (`854x480`, `1280x720`, `1920x1080`): panel containment, header/main/footer bounds, three-column control bounds and scroll clamping. It does not verify rendering, hover state, tooltips, all row bounds, GUI scales, or client lifecycle.

## Release blockers remaining

1. Full Fabric screen interaction and rendering has not been ported; the rejected workspace family is still present in source, although unreachable.
2. No direct visual screenshot comparison or in-game GUI runtime exercise exists.
3. Existing readiness blockers remain: executor consolidation, profiler scheduler migration, policy/guard completion, overhead monitor, configuration migration tests, deferred command hiding, JFR/A-B evidence, and complete runtime/JAR gates.
4. Therefore no JAR export is authorised.
