# GradleMC Forge 1.20.1 v1.0.4 — Phase 2 incremental verification

Date: 2026-07-23. This document records completed, reproducible work only.

## Corrected behaviour

* `LegacyGradleMCScreen` remains the active GUI destination. The restored
  sections now provide command-backed overview, quick-action, test, profiler,
  report and about controls, plus a bounded wheel scroll offset.
* Settings exposes every existing overlay boolean, mode, position, scale,
  rolling sample window, update interval, background switch, and background
  opacity. Opacity is clamped to `0.0..1.0` before the Forge config is saved.
* Adaptive Risk is separate from Technical Stability. A normal server sample
  now recomputes after decay and synchronizes one compact status every 40
  ticks. The historical apparent `8/100` freeze was caused by missing normal
  snapshot publication, not by a scoring constant.

## Current evidence and limits

Adaptive Risk uses local player-context signals: darkness, underground time,
recent damage/deaths/kills, nearby hostiles, health, food, movement, dimension,
and sleep time. Its calm value is configured by `baseThreatGain` (default 8)
and is not technical-health evidence. Technical Stability uses the existing
smart evidence/baseline subsystem and must be interpreted separately.

The managed output root remains `<gameDir>/gradlemc/` with report, export,
issue-bundle, profile, and rules subdirectories as provided by `GradleMcPaths`.
No external service, telemetry, network inference, remote download, or shell
execution was added.
