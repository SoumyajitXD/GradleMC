# v1.0.4 Phase 3C performance baseline

Recorded 2026-07-24 before the Phase 3C implementation build. The local verification JAR was `build/libs/gradlemc-1.0.4-forge-1.20.1.jar`, SHA-256 `0C14C66FAD8EDDC256C9BBD2CD2010287BBCB7F5ED8D469F31FED65953E7FB88`.

The audit covered `GradleMC`, client events, overlay, GUI, task engine, profiler, adaptive manager, networking, reports, and managed paths. Client hot callbacks are one END client tick and one post-GUI render callback. Server callbacks include adaptive sampling, performance tests, worldgen observation, profiler, and health ticks.

Confirmed defects: the overlay read configuration and invoked its FPS window setter once per rendered frame, and recalculated unchanged text widths every render. Both are fixed. Render/tick callback inspection found no file reads. Worker owners remain Foundation (1--2, queue 16), profiler report (1, queue 2), profiler sampler (1 scheduled daemon), and investigation (1 direct-handoff); consolidation is incomplete.

No controlled in-game A/B recording was available. Java 17 `compileJava`, `test`, and `gradlemcSelfTest` passed after one transient ForgeGradle TLS certificate-validation failure during an earlier combined invocation. No development timing is presented as production overhead.
