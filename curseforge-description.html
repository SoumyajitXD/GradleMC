What is GradleMC?

Modded Minecraft problems often collapse into the same diagnostic masterpiece: “it feels laggy.” That is not evidence.

GradleMC gives players, modpack creators, server owners, testers and developers a structured way to inspect a Minecraft instance before changing random settings or deleting half the modpack. It gathers relevant local information, measures bounded runtime signals, performs rule-based checks and turns the available evidence into readable diagnostic output.

The workflow

01 — Inspect

Review Minecraft, loader, JVM and GradleMC information alongside loaded mods, configurations, paths, memory state and relevant environment details.

02 — Measure

Observe supported runtime signals such as FPS, frame behaviour, memory pressure, TPS/MSPT, entities, block entities, world-generation activity and bounded profiling information.

03 — Diagnose

Use local rule-based Smart Diagnostics to connect available evidence, identify suspicious conditions, expose missing information and produce prioritised guidance.

04 — Export

Generate readable reports and diagnostic evidence for troubleshooting, bug reports, controlled comparisons, support requests and modpack maintenance.

Core capabilities

Diagnostics control centre

  • Open the in-game GradleMC interface using /gradlemc gui or the configurable keybind where supported.
  • Access diagnostics, runtime information, reports, performance tools and supported settings from one interface.
  • Inspect the current state of the instance without leaving Minecraft.

Environment and mod inspection

  • Minecraft, loader, GradleMC and JVM/runtime information.
  • Operating-system and environment context.
  • Loaded-mod summaries and inspection tools.
  • Configuration, report and other relevant local paths.
  • Heap and JVM memory information.

Performance evidence

  • Current FPS and optional average FPS information on supported clients.
  • Bounded timed FPS tests.
  • TPS/MSPT-related observations where supported.
  • Memory-pressure and runtime-health signals.
  • Entity, block-entity and world-generation observations.
  • Lightweight bounded performance sampling.

Smart Diagnostics

  • Local rule-based diagnostic scoring.
  • Prioritised diagnostic advice.
  • Supporting evidence and missing-data context.
  • No generative AI and no remote inference.

Reports and troubleshooting evidence

  • Readable locally generated diagnostic reports.
  • Recent-report discovery through supported commands and interfaces.
  • Performance and diagnostic summaries.
  • Exportable evidence for bug reports and support requests.

GradleMC uses deliberately bounded diagnostic sampling. It is a troubleshooting utility, not async-profiler wearing a Minecraft skin.

Installation — Forge 1.20.1 v1.1.0

  1. Install Minecraft Java Edition 1.20.1 with Forge.
  2. Use Java 17 for Minecraft 1.20.1.
  3. Download gradlemc-1.1.0-forge-1.20.1.jar.
  4. Download Kotlin for Forge.
  5. Place both required mod jars in the instance or server mods folder.
  6. Launch Minecraft.
  7. Run /gradlemc to inspect the command tree supplied by the installed build.

Do not confuse implementation language with runtime.

GradleMC v1.1.0 has been rewritten in Kotlin and its previous Java implementation was removed. Minecraft Forge 1.20.1 still requires a Java 17 runtime.

Use the exact build

Minecraft versions and mod loaders are not interchangeable. A Forge build is not a Fabric build. A Fabric build is not a NeoForge build. Renaming a jar changes the filename, not its compatibility.

Always check the GradleMC Files page and choose the file matching your Minecraft version and loader.

Quilt support has ended

No new GradleMC versions are planned for Quilt.

The Quilt release line received too few downloads to justify continuing the additional development, testing and maintenance required for another loader.

Existing Quilt releases may remain available as legacy downloads, but new GradleMC features, fixes and releases will not be ported to Quilt.

Maintaining another loader multiplies compatibility work, testing and opportunities for something to catch fire in a loader-specific way. Development effort is better spent on GradleMC versions people are actually using.

Essential commands

GradleMC commands are lowercase. Exact availability can vary by release, permissions and client/server side.

  • /gradlemc — inspect the command tree available in your build.
  • /gradlemc gui — open the diagnostics interface where supported.
  • /gradlemc status — show a compact diagnostic status summary.
  • /gradlemc version — show GradleMC and environment version information.
  • /gradlemc memory — inspect JVM memory information.
  • /gradlemc check — run available local diagnostic checks.
  • /gradlemc testfps start <seconds> — begin a bounded client FPS test where supported.
  • /gradlemc testfps stop — stop an active FPS test.
  • /gradlemc perf start <seconds> — start a supported bounded performance sample.
  • /gradlemc export — export local troubleshooting evidence.
  • /gradlemc reports latest — locate the newest generated report.
  • /gradlemc smart score — inspect the current Smart Diagnostics score.
  • /gradlemc smart advice — inspect prioritised diagnostic guidance.

Generated files

GradleMC stores its local diagnostic data beneath:

<gameDir>/gradlemc/

Depending on the installed release and action used, this directory can contain diagnostic reports, exports, profiling information, issue evidence, configuration-related files and other GradleMC output.

Review diagnostic files before sharing them. Reports can contain local paths, Java/JVM information, loaded mod names, loader details, instance information and other system context.

GradleMC does not automatically upload these reports.

Local by design

  • No behavioural telemetry.
  • No analytics tracking.
  • No cloud AI or LLM integration.
  • No hidden remote diagnostic inference.
  • No automatic report upload.
  • No broad scanning of unrelated private files.
  • Your generated evidence remains local until you choose to share it.

Smart Diagnostics is not generative AI. It is a local rule-based diagnostic system designed to evaluate available GradleMC evidence and return structured guidance.

What GradleMC is not

  • Not an FPS booster: GradleMC measures and diagnoses performance; it does not manufacture additional GPU horsepower.
  • Not a crash-fixing bot: it can expose useful evidence, but it cannot automatically repair every incompatible or broken modpack.
  • Not a replacement for performance mods: it does not replace Sodium, Embeddium or careful configuration.
  • Not a full low-level profiler: advanced investigations may still require Spark, Java Flight Recorder, VisualVM or async-profiler.
  • Not a universal jar: use the correct Minecraft-version and loader-specific build.
  • Not a Gradle replacement: GradleMC and the Gradle Build Tool are separate projects.
  • Not a Bedrock Edition tool: GradleMC targets supported Minecraft Java Edition releases.

GradleMC can tell you that your performance problem has evidence behind it. It cannot negotiate extra frames from hardware that has already submitted its resignation letter.
