Built for evidence, not guesswork

When Minecraft feels wrong, find out why.

Stuttering, low FPS, memory pressure, overloaded servers, mod conflicts and bad configurations can look remarkably similar. GradleMC helps players, modpack creators, testers and server administrators understand what is running and gather useful data before changing things at random.

Environment / 01

Know your setup

Inspect supported Minecraft, loader, GradleMC, JVM, operating-system, mod and memory information. Verify the environment you are actually troubleshooting.

Performance / 02

Measure, don't assume

Capture bounded FPS or performance samples where supported. Review available memory, TPS/MSPT, entity, block-entity and world-generation signals.

Smart Diagnostics / 03

Understand the signals

Use local rules, scoring and prioritised advice to highlight suspicious conditions and explain where more evidence is needed. No cloud inference.

Reports / 04

Keep usable evidence

Export local troubleshooting reports for comparisons, support requests and bug reports. TXT and JSON outputs are available in supported releases.

Smart Diagnostics • Local by design

Guidance based on evidence, not a chatbot.

GradleMC's Smart Diagnostics applies local rules and scoring to available diagnostic information. It can flag possible issues, prioritise advice and identify gaps in the evidence. It does not send data to an AI service, perform LLM inference or guarantee a definitive root cause.

Quick start • v1.1.0 for Minecraft 1.20.1

Install the right dependencies.

Forge • Java 17

Forge installation

  1. Set up Minecraft 1.20.1 with compatible Forge and Java 17.
  2. Install Kotlin for Forge.
  3. Add the GradleMC Forge jar to your mods folder.
  4. Start Minecraft and run /gradlemc.

Jar: gradlemc-1.1.0-forge-1.20.1.jar

Fabric • Java 17

Fabric installation

  1. Set up Minecraft 1.20.1 with compatible Fabric Loader and Java 17.
  2. Install Fabric API and Fabric Language Kotlin.
  3. Add the GradleMC Fabric jar to your mods folder.
  4. Start Minecraft and run /gradlemc.

Jar: gradlemc-1.1.0-fabric-1.20.1.jar

Important: Kotlin does not replace Minecraft's Java runtime. The two 1.20.1 v1.1.0 builds require Java 17 and their listed loader-specific dependencies. For 1.21.11 and 26.1.2, follow the dependencies of the exact selected file.

Control and commands

Diagnostics at your fingertips.

Use the diagnostics GUI where supported, or run lowercase /gradlemc commands. The installed build's command tree is authoritative: commands and permissions vary by Minecraft version, loader and client/server side.

/gradlemc gui
Open the diagnostic interface where supported.

/gradlemc status
Get a compact current status summary.

/gradlemc version
Inspect version and environment context.

/gradlemc memory
Review JVM memory information.

/gradlemc check
Run available diagnostics.

/gradlemc export
Export local evidence.

/gradlemc reports latest
Find the newest report.

/gradlemc smart advice
Review rule-based suggestions.

Additional supported commands include timed FPS tests, performance sampling, and Smart Diagnostics scoring. Client-only tools do not run on headless dedicated servers.

Privacy first

Your diagnostics stay yours.

No behavioural telemetry. No analytics tracking. No cloud AI or LLM service. No automatic report uploads.

GradleMC generates diagnostic information locally and does not automatically transmit your exported troubleshooting evidence. Generated output is stored beneath <gameDir>/gradlemc/ where supported.

Before you share: review reports for local paths, mod names, JVM details and other instance or system information.

What GradleMC is — and isn't

A diagnostics utility, not an FPS booster. It gathers clues and measurements; it does not automatically optimise your GPU or repair every broken modpack.

A practical first stop, not a replacement for deep profilers. Investigations may still require tools such as Spark, Java Flight Recorder or async-profiler.

For Minecraft Java Edition, not Bedrock. Only listed, published loader/version combinations are supported.

An optional client-side runtime overlay in a supported build; available fields vary by release.

Support and development

Found a bug? Bring the evidence.

For reproducible GradleMC issues, include your Minecraft version, loader and loader version, GradleMC jar, Java version, dependency versions, reproduction steps, expected versus actual behaviour, and relevant reviewed logs or reports. Screenshots are helpful for interface bugs.
